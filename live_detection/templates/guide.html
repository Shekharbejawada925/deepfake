PROJECT GUIDE

Model setup &
research scope

1. Install your supplied model

The GitHub source excludes large model weights. Run python -m tools.install_checkpoint /path/to/Deepfake_Streaming_Project_Updated.zip from the application folder. This installs your existing checkpoint at models/legacy_detector.pt beside the included JSON profile. Restart the app to use it. The startup check verifies the checkpoint bytes and tensor shapes.

Predictions use a compatibility mode: the original graph scores only the final face in each window. The class order comes from the uploaded app and has not been verified using training labels. Scores are provisional.

A separate corrected temporal model is available through the workflow in docs/MODEL_SETUP.md. Train it with labeled data, then set MODEL_PATH=models/detector.pt and restart. Changing the old model’s LSTM layout at inference would change the meaning of its learned weights.

2. Choose an input

Upload: a readable video file, analyzed in chronological windows up to the configured duration limit.

Webcam: a browser camera, accessible on localhost or an HTTPS site. Frames are captured at the model’s sampling rate; incomplete or irregular windows receive no verdict.

Screen video: share the tab or window playing your video. Enlarge the face and keep this analysis page visible beside it. The browser asks for permission; protected video may appear black. Stop sharing ends capture. No audio is captured.

Stream URL: add the camera or media host to STREAM_ALLOWED_HOSTS in .env, then restart. Use a direct RTSP, HLS or HTTP media endpoint. Allow only media sources you control or trust; redirects and HLS segments must also stay within your intended network boundary.

3. Read the results

Likely real / likely fake: the window’s score crosses a configured threshold. Inconclusive: the score is ambiguous, the face is unusable, multiple faces appear, or a corrected temporal sequence is incomplete. Flagged segments: at least one sampled window crossed the fake threshold.

Default thresholds are provisional (fake score ≤ 0.20 for likely real, ≥ 0.80 for likely fake). Fit temperature and thresholds on a separate validation set; report final metrics on untouched test subjects. Do not change class labels or thresholds just to make one video look correct.

4. What follows the paper

The corrected training model uses a ResNeXt50_32x4d encoder, 112 × 112 RGB face crops, 2048-dimensional features and a one-layer LSTM with 2048 hidden units. Its LSTM uses batch-first input correctly. The supplied legacy checkpoint keeps its original BGR and final-frame behavior until a corrected model is trained. The paper’s abstract says ResNet50 while its methodology specifies ResNeXt50; this rebuild follows the methodology and uploaded code.

The paper reports 94.3% accuracy, but this rebuild has not reproduced that result. It also mixes 30 fps preprocessing with 10 fps inference. Sampling rate and window length are now explicit checkpoint settings shared by training and inference.

5. Practical limits

Streaming is window-based. The bundled legacy profile reports every ten sampled frames at 10 fps, about one second plus processing. It can score a partial upload window because it uses only the final face. Corrected temporal checkpoints need a complete trained sequence. CPU processing may add substantial delay; use measured latency to choose hardware. No claim of instant detection or guaranteed accuracy is made.

The portable default uses OpenCV Haar face detection. A HOG option matches the original detector family but needs the optional face-recognition dependency and matching training preprocessing. Single-face continuity is checked geometrically; this is not identity tracking.

The server is intended for one local research workspace. Keep one server process. Authentication, network egress isolation and persistent multi-user job infrastructure are required before public deployment. Uploaded sources are deleted after processing. Preview frames and reports expire when a later API request triggers cleanup, or when the server restarts.
